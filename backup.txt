Что уже сделано (реализованные фичи)
1. ML модель
Обучена модель Random Forest на 208 897 URL
Точность модели: 98.1%
Признаки: длина URL, количество точек, дефисов, слешей, параметров, наличие IP, HTTPS, подозрительные слова (login, verify, account, admin, cp.php), сокращатели ссылок (bit.ly, goo.gl, tinyurl), длина домена.

2. Обработка данных
Собраны и очищены датасеты фишинговых и легитимных URL.
Добавлены доверенные домены (Google, Yandex, VK, Wikipedia, GitHub и др.) с меткой label=0.
Добавлены опасные примеры (IP-адреса, короткие ссылки, подмена брендов) с меткой label=1.
Балансировка классов обеспечена.

3. Веб-сервер (Flask)
Эндпоинты:
/ – главная страница
/check – проверка URL (POST)
/feedback – приём обратной связи (POST)
/admin/feedbacks – админ-панель с таблицей отзывов
/download-db – скачивание базы отзывов
/health – проверка статуса
Кэширование результатов (TTL 24 часа).
Белый список доверенных доменов (мгновенный вердикт safe).

Эвристики:
IP-адрес → 95% опасности (dangerous)
Короткие ссылки (bit.ly и др.) → 70% подозрительности (suspicious)
Ограничение ML-предсказания для подозрительных слов максимум 70%, чтобы они не уходили в dangerous.
Валидация URL (нормализация, проверка схемы, наличия точки в домене).
Обработка невалидных URL: при сохранении отзыва поле model_verdict очищается.

4. Фронтенд
Адаптивный интерфейс на HTML/CSS/JS.
Форма ввода URL, кнопка проверки.
Отображение результата (цветной блок, процент опасности, объяснение).
Форма обратной связи (оценка пользователя, комментарий).
Анимация загрузки, фавиконка.
Обработка ошибок сети и невалидного ввода.

5. База данных (SQLite)
Таблица feedbacks для хранения отзывов.
Функции инициализации, сохранения, получения всех отзывов.
Поддержка скачивания БД через админку.

6. Деплой и инфраструктура
Dockerfile.
Развёртывание на Render (бесплатный хостинг).
Автоматический деплой из GitHub (git push → автообновление).
Репозиторий GitHub (70+ коммитов).

7. Документация
Презентация (слайды) с описанием архитектуры, спринтов, демонстрацией.
